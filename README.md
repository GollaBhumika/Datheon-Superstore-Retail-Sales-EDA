# Datheon – Superstore Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a Superstore Retail Sales dataset to understand sales performance, customer purchasing behavior, product category revenue, regional sales distribution, monthly trends, and discount impact on profitability.

The objective is to clean and analyze retail sales data using Python and identify meaningful business insights to support data-driven decision-making.

## Project Objectives
- Perform data cleaning and preprocessing.
- Identify and handle missing values and duplicate records.
- Analyze customer purchase volume.
- Explore monthly sales trends and seasonality.
- Evaluate category-wise and region-wise sales and profit.
- Analyze the relationship between discounts and profitability.
- Develop at least five actionable business insights.

## Dataset
- **Dataset Name:** Superstore Retail Sales
- **Source:** Datheon Dataset
- **Format:** CSV

## Key Business Questions
- Which product category generates the highest sales?
- Which region contributes the most revenue?
- Which customer segment has the highest purchase volume?
- Which months experience higher sales?
- How do discounts affect profitability?

## Expected Deliverables
- Cleaned and analyzed retail sales dataset.
- Jupyter Notebook containing Python analysis.
- Data visualizations and charts.
- Minimum five executive business findings.
- Business recommendations based on analytical results.

## Conclusion
This project demonstrates practical skills in data cleaning, exploratory data analysis, data visualization, and business insight generation using Python. The analysis aims to transform raw retail sales data into meaningful information that supports better business decisions.
